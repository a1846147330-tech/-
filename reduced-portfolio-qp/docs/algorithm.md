# 算法和输入

求解流程：差分 → 滚动 3σ 去极值 → 15 行收益和的统计量 → 构造凸 QP → Mehrotra 预测校正内点法 → 指标和 JSON 输出。

Newton 矩阵为 K = H + Aᵀ diag(z/s) A + 1e-10 I。换手辅助块 T = diag(d) + ρ11ᵀ，用 Sherman–Morrison 公式求其逆作用，构造 8×8 Schur 补；预测和校正方向共享分解。失稳时回退完整 16×16 Cholesky 分解。等式乘子再通过标量消元处理。

停止条件使用未正则化原问题的残差 < 1e-9，最多 80 轮；还检查恢复权重的约束违反程度 <= 1e-7。最大分散目标用齐次变换，并同时缩放组界和换手限制。

输入为 OLE/BIFF `.xls` 的第一张工作表。首行为表头，其后每行恰好 9 个数值：Windows 1900 日期系统的整数日期序号，以及 8 个策略的累计收益水平（先做差分，不是百分比收益率计算）。日期严格递增。建议至少 120 行，以包含多个调仓点。

仅支持源码实现的 NUMBER/RK/MULRK 数值记录，不支持公式、加密、1904 日期系统或 mini-stream 工作簿。文件最多 64 MiB。Windows 文件访问使用 ANSI API，建议仓库及输入路径使用 ASCII 字符。
